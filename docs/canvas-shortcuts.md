# Canvas keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| V / H / P / E / A / T | Select / pan / pen / eraser / arrow / text |
| Cmd/Ctrl+A | Select unlocked shapes |
| Cmd/Ctrl+C/X/V | Copy / cut / paste |
| Cmd/Ctrl+D | Duplicate selection |
| Cmd/Ctrl+G | Group selection |
| Cmd/Ctrl+Shift+G | Ungroup selected group |
| Cmd/Ctrl+L | Lock or unlock selection |
| Cmd/Ctrl+Z | Undo |
| Cmd/Ctrl+Shift+Z | Redo |
| Delete / Backspace | Delete unlocked selection |
| Arrow keys | Nudge; Shift increases the step |
| Space + drag | Pan without leaving the active tool |
| Escape | Clear selection and return to select |

Text editing uses Enter for line breaks and Cmd/Ctrl+Enter to commit.
